# Живая проверка ARQA-1 на Petstore

23 ноября 2026 года. Контракт [Demo Petstore 1.0.0](../demo/petstore/openapi.yaml), стенд Linux под WSL. CLI вызвал ReAct-агента с реальной моделью Qwen3.8-27B. Агент запустил Schemathesis через testing_tools и подготовил отдельный pytest-набор. Эталонные HTTP-запросы и pytest выполнялись на разных чистых экземплярах того же сервиса. На их результаты не влияло состояние, оставшееся после Schemathesis.

## Сверка с контрактом

| Дефект | Запрос | Ожидание по OpenAPI | Ответ на прямой запрос | Schemathesis | Pytest |
|---|---|---|---|---|---|
| P1 | `GET /pets?limit=101` | 400 | 500, `{"detail":"internal error"}` | найден | найден |
| P2 | `POST /pets` с пустым `name` | 422 | 500, `{"detail":"internal error"}` | найден | найден |
| P3 | `POST /pets` с `{"name":"tom","tag":"cat"}` | 201, обязательное поле `status` | 201, `{"id":3,"name":"tom","tag":"cat"}` | найден | найден |
| P4 | `DELETE /pets/999` | 404 | 200, `{"deleted":false}` | найден | найден |

Контрольный запрос `GET /pets/1` вернул 200 и `"status":"available"`. Schemathesis выдал 10 находок, которые соответствуют четырём уникальным дефектам. Pytest выполнил 21 тест. Прошли 13, упали 8 на расхождениях с контрактом. Ошибок запуска и пропусков не было. Сценарий «создать и прочитать» остановился на создании из-за P3.

## Метрики

| Метрика | Формула и наблюдение | Schemathesis | Сгенерированный pytest |
|---|---|---:|---:|
| Охват операций | Операции с наблюдаемым ответом / все операции контракта | 4/4 (100%) | 4/4 (100%) |
| Охват кодов ответов | Наблюдаемые документированные пары «операция, код» / все документированные пары | 8/10 (80%) | 9/10 (90%) |
| Fault Detection Rate | Найденные уникальные эталонные дефекты / все эталонные дефекты | 4/4 (100%) | 4/4 (100%) |
| Test Suite Size | Число собранных pytest-кейсов | — | 21 |
| Запуск без ручной правки | Тесты, дошедшие до HTTP-ответа / все собранные тесты | — | 21/21 (100%) |
| Runnability в testing_tools | Тесты со статусом passed на исходном сервисе / все собранные тесты | — | 13/21 (61,9%) |
| Mutation Score в testing_tools | Убитые / (убитые + выжившие) | — | 16/16 (100%) |

Мутационный прогон выполнен на четвёртом чистом экземпляре Petstore с `seed=1` и лимитом 30 мутантов. 16 мутантов убиты, 14 остались без покрытия. Если считать от всех 30 мутантов, обнаружено 16/30 (53,3%). По формуле testing_tools Runnability ниже порога 70% из ПМИ, поскольку в числителе только прошедшие тесты. Для формальной оценки нужно применить правила из отдельной методики качества тестов.

Весь CLI-прогон занял 58,5 с, из них 6,8 с занял Schemathesis. Провайдер сообщил 23 968 токенов за 3 вызова модели. Это результаты одного контракта. Второй сервис, Microcks и формальная повторяемость трёх прогонов в эту проверку не вошли.

## Воспроизведение

Установите workspace через `uv sync --locked`, настройте `DEEPCODE_*` и поднимите testing_tools в режиме `TT_TOOL_MODE=real`. Если используете WSL или запускаете стенд без Docker, откройте отдельный терминал для каждого экземпляра. В примере все процессы находятся в одной сети. В Docker укажите адреса, доступные тому процессу, который выполняет запрос.

```bash
TT_TOOL_MODE=real uv run --locked testing-tools
```

Из корня репозитория запустите Petstore на портах 18081, 18082, 18083 и 18084, меняя `--port` в каждой команде.

```bash
PYTHONPATH=demo uv run --locked uvicorn --app-dir demo/petstore app:app --port 18081
```

```bash
uv run --locked arqa-testgen generate demo/petstore/openapi.yaml \
  --base-url http://127.0.0.1:18081 \
  --tools-url http://127.0.0.1:8000/api/v1 \
  --generate-tests

uv run --locked python demo/evaluate_petstore.py runs/<run-id>/report.json \
  --reference-url http://127.0.0.1:18082 \
  --pytest-url http://127.0.0.1:18083 \
  --mutation-url http://127.0.0.1:18084
```

Из вывода CLI возьмите точный путь к `report.json`. Рядом скрипт сохранит `petstore-evaluation.json` и `generated-pytest.xml`, а при мутационном прогоне также `petstore-mutation.json`. Для следующего измерения перезапустите Petstore, чтобы восстановить начальные данные.
